# Academic Website

Hugo-based personal academic research portfolio for PhD applications, faculty contact, CV access, and research project presentation.

## Local Preview

```sh
hugo server
```

## Content Editing

- Home: `content/_index.md`
- About: `content/about/_index.md`
- Projects: `content/projects/`
- Public images: `static/images/`
- CV PDF: `static/cv/`
- Raw source materials: `website-content/`

The `website-content/` directory is for original notes, drafts, and research assets. Do not delete it when editing the Hugo site.
